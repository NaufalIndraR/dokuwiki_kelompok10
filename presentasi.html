Latar Belakang & Pemilihan Aplikasi

Berdasarkan Kurasi Awesome-Selfhosted & Panduan auriza/komdat-lab

Kebutuhan Riil Laboratorium

Laboratorium jaringan memerlukan dokumentasi teknis yang terpusat untuk topologi, subnetting, instruksi rute, dan konfigurasi server yang dapat diakses cepat oleh mahasiswa dan asisten tanpa hambatan beban server.

Kesesuaian Rule Projek

Kategori: Wikis pada Awesome-Selfhosted.
Legalitas: 100% Legal & Open Source (Lisensi GPLv2).
Bandingan Asli: Dibandingkan dengan MediaWiki (Wikipedia) dan BookStack.

  • Bebas dari dependensi basis data SQL (sepenuhnya flat-file berbasis berkas teks).
  • Konsumsi RAM operasional terendah di kelasnya (< 64 MB), ramah VPS mikro.
Slide 3 / 11

Arsitektur Flat-File DokuWiki

Keunggulan Desain Tanpa Basis Data Relasional SQL

  • Storage Sederhana: Seluruh artikel disimpan langsung sebagai berkas teks biasa di direktori data/pages/.
  • Riwayat Revisi Bawaan: Perubahan dokumen disimpan dalam data/attic/ lengkap dengan visual perbandingan (diff) dan rollback.
  • Zero Database Overhead: Tidak ada risiko crash server database MySQL atau habisnya connection pool.
  • Portabilitas Maksimal: Pencadangan dan pemindahan data hanya memerlukan kompresi folder (tar / zip).

Struktur Direktori Kritis

dokuwiki/
├── data/
│   ├── pages/       # Konten wiki (.txt)
│   ├── attic/       # Riwayat revisi
│   └── media/       # Gambar modul
├── conf/            # Konfigurasi & ACL
└── lib/plugins/     # Ekstensi sistem

Topologi & Metode Deployment

Dukungan Dua Metode Instalasi Fleksibel

1. Docker Compose (Dokploy / VPS)

Menggunakan container terstandarisasi untuk kecepatan deployment dan isolasi environment:

services:
  kelompok10-dokuwiki:
    image: lscr.io/linuxserver/dokuwiki:latest
    ports:
      - "8080:80"
    volumes:
      - dokuwiki_config:/config

2. Native LAMPP (Ubuntu Server)

Instalasi native berkinerja tinggi menggunakan skrip automasi setup.sh:

  • Web Server: Apache 2.4 + mod_rewrite
  • PHP 8.x + Ekstensi XML, GD, Mbstring
  • VirtualHost dengan isolasi direktori privat

Konfigurasi Server & Keamanan

Optimasi Parameter, URL Bersih, dan Hak Akses

Optimasi PHP & Clean URLs

Batas Ukuran Upload & Memori:
upload_max_filesize = 32M
post_max_size = 32M
memory_limit = 256M

Nice URLs (Clean URLs):
Mengaktifkan Apache .htaccess dan modul rewrite sehingga URL menjadi ringkas tanpa doku.php?id=.

Access Control List (ACL) & Proteksi

Pengaturan Izin Berjenjang:
• @ALL (Tamu): Read-only halaman publik.
• @user (Mahasiswa): Read & Edit materi praktikum.
• @admin (Asisten/Dosen): Pengelolaan penuh & backup.

Proteksi Direktori:
Direktori data/, conf/, bin/, dan inc/ diisolasi via Apache agar tidak dapat diakses langsung oleh publik.

Slide 7 / 11

Maintenance & Backup Otomatis

Pencadangan Terjadwal Bebas Downtime Database

Pencadangan otomatis dilakukan oleh skrip backup.sh yang mengompresi data wiki, konfigurasi, dan plugin:

tar -czf "$BACKUP_FILE" \
    --exclude="$DOKUWIKI_DIR/data/cache/*" \
    -C "$DOKUWIKI_DIR" data conf lib/plugins lib/tpl

Dilengkapi retensi otomatis untuk menghapus arsip lama berusia lebih dari 14 hari.

Penjadwalan Cron Job

Backup berjalan otomatis setiap malam pukul 02.00 WIB:

0 2 * * * /bin/bash /var/www/dokuwiki/backup.sh > /dev/null 2>&1

Prosedur Restore Cepat

sudo tar -xzf /var/backups/dokuwiki_backup_*.tar.gz \
    -C /var/www/dokuwiki/
Slide 8 / 11

Pengisian Konten: Knowledge Base Lab

Pusat Dokumentasi Praktikum Komdat Kelompok 10

Modul 1 & 2

Modul 1: Desain Topologi & Subnetting
Arsitektur bintang hierarkis, alokasi VLSM 192.168.10.0/24 (VLAN 10, 20, 30, 40), dan konfigurasi sub-interface Linux.

Modul 2: Routing Statik & Dinamik
Forwarding kernel IPv4, static route hop-by-hop, dan protokol dynamic OSPF Area 0 dengan FRRouting.

Modul 3 & 4

Modul 3: Konfigurasi Layanan Jaringan
DNS otoritatif BIND9 (labkomdat.ipb.ac.id), ISC-DHCP-Server lease alokasi otomatis, dan Apache web server.

Modul 4: Network Security & Hardening
Firewall stateful UFW/iptables, SSH Key Authentication port 2222, dan pencegahan brute-force Fail2Ban.
