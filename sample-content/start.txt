====== Portal Dokumentasi Praktikum Komunikasi Data dan Jaringan Komputer (KDJK) ======

Portal ini memuat dokumentasi teknis, prosedur konfigurasi jaringan, serta panduan praktikum untuk mata kuliah **Komunikasi Data dan Jaringan Komputer (KDJK)**, Departemen Ilmu Komputer - IPB University.

Seluruh dokumentasi dikelola secara mandiri (*self-hosted*) menggunakan DokuWiki berbasis penyimpanan berkas teks (*flat-file*).

===== Navigasi Modul Praktikum =====

Daftar materi dan modul praktikum dikelompokkan ke dalam beberapa topik utama:

==== 1. Infrastruktur Dasar & Pengalamatan ====
  * [[:kdjk:subnetting|Perancangan Subnetting IPv4 & IPv6]]: Perhitungan CIDR, VLSM (*Variable Length Subnet Mask*), dan alokasi blok IP laboratorium.
  * [[:kdjk:switching|Konfigurasi Switching & VLAN]]: Segmentasi jaringan lokal, mode access/trunk (IEEE 802.1Q), dan inter-VLAN routing.

==== 2. Protokol Routing ====
  * [[:kdjk:routing_statik|Routing Statik]]: Penentuan rute manual (*next-hop*) dan konfigurasi default gateway.
  * [[:kdjk:routing_dinamik|Routing Dinamik (OSPF & RIP)]]: Pembentukan tabel routing otomatis, konfigurasi *Area 0* OSPF, dan propagasi rute.

==== 3. Layanan Jaringan (Network Services) ====
  * [[:kdjk:layanan_dns|Domain Name System (BIND9)]]: Pemetaan domain internal, konfigurasi zona *forward* dan *reverse lookup*.
  * [[:kdjk:layanan_dhcp|Dynamic Host Configuration Protocol]]: Distribusi IP otomatis pada subnet klien praktikum.
  * [[:kdjk:layanan_web|Web Server (Apache/Nginx)]]: Deployment layanan web berbasis Linux dan konfigurasi VirtualHost.

==== 4. Keamanan Jaringan ====
  * [[:kdjk:firewall|Firewall & Packet Filtering]]: Pengaturan aturan *iptables* dan *UFW* (Uncomplicated Firewall).
  * [[:kdjk:hardening|SSH Hardening]]: Otentikasi berbasis pasangan kunci publik/privat (*public-key authentication*) dan pengubahan port default.
